Opt-In Process

Homelab Notifications · Operated by Gavin Hernandez

Who can receive messages

Homelab Notifications sends automated alerts about a personal home server to one recipient: the program operator, Gavin Hernandez, on the operator's own mobile number. There is no public sign-up, web form or keyword campaign, and no third parties are messaged.

How opt-in happens

  1. The operator opens the server's private notification settings file, which only the operator can access.
  2. Next to the phone-number setting, the file shows the consent disclosure below.
  3. The operator enters the operator's own mobile number in that setting and saves it. Entering the number is the operator's express consent to receive the alerts described.
  4. Messages start only after this step. Replying STOP at any time ends them; HELP returns help information.

Consent disclosure shown at the point of opt-in

SMS CONSENT (Homelab Notifications, operated by Gavin Hernandez): By adding your mobile number below you agree to receive automated text alerts about this home server (e.g. disc copy started/finished). Message frequency varies, typically 0-10 per day. Message and data rates may apply. Reply STOP to opt out, HELP for help. Consent is not a condition of any purchase. Only add numbers you own.
