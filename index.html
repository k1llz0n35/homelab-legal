Homelab Notifications

Operated by Gavin Hernandez (individual / sole proprietor)

About the program

Homelab Notifications is a private, non-commercial alert service. It sends automated text messages (SMS) about the status of a personal home server operated by Gavin Hernandez. Examples include a disc copy starting or finishing, or a backup completing.

The program sends no marketing, promotional or advertising messages. It sends nothing to members of the public.

Who receives messages and how they opt in

The only recipients are mobile numbers belonging to the program operator, Gavin Hernandez, which the operator adds to the server's configuration. There is no public sign-up form. Adding a number to that configuration is the operator's express consent to receive these messages.

Message frequency varies with server activity, typically 0–10 messages per day. Message and data rates may apply. Reply STOP to opt out, or HELP for help.
